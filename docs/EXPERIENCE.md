# 📱 如何使用已上线的「拾光」微信小程序

这个项目有两种使用方式，**请先区分：**

| 你是谁 | 应该怎么做 |
| --- | --- |
| 普通微信用户 | 通过微信搜索正式上线名称或扫描官方小程序码进入线上版，无需 GitHub 账号 |
| 开发者 | 克隆 GitHub 源码，在自己的微信开发者工具、云环境中运行；参见 [DEVELOPMENT.md](DEVELOPMENT.md) |

## 方式 A：微信直接进入正式版（普通用户推荐）

1. 在手机上打开微信，点击 **发现 → 小程序**，使用正式上线的小程序名称搜索（发布者须确认微信的实际展示名称以及是否允许搜索）。
2. 或者用微信扫描**官方小程序码**，直接打开线上版本。

**目前本仓库还没有上传已核验的官方小程序码。** 为防止用户扫到错误或过期的图片，暂不放置虚假二维码或未经确认的第三方链接。等维护者上传小程序码后，本文件与首页将直接显示扫码入口。

### 维护者：如何获取并公开正确的小程序码

1. 登录 [微信公众平台](https://mp.weixin.qq.com/) 中的**拾光小程序账号**。
2. 在 **设置 → 基本设置** 中查找 **小程序码**、**小程序码及线下物料下载** 等入口（具体名称依后台版本可能变化）。
3. 下载能访问**线上正式版本**的小程序码，使用微信扫码自行测试它能打开正确的小程序。
4. 将图片命名为 `docs/assets/wechat-miniapp-code.png`，提交至此公开仓库；然后在 README 的线上体验区域插入：`![微信扫码体验拾光](docs/assets/wechat-miniapp-code.png)`。
5. 可同时提交正式展示名称、支持搜索的名称和 2～4 张真实界面截图。

**不要将小程序开发版预览码、体验版二维码或任意普通网址的 QR 码当作正式线上小程序码。**

### 能不能做成一个点击就打开微信的小程序链接？

微信提供过 URL Link / Scheme 等能力，但**适用主体、配额和有效期有条件**，尤其个人主体不能直接假定可开通。若账号具备官方生成权限并取得可公开使用的有效链接，可以补到此页面。未经证实前，不写虚假的“立即打开”地址。

## 方式 B：下载源码自行体验（开发者）

参见 [完整部署指南](DEVELOPMENT.md)。这里的代码是**示例演示版**，仅提供每种词库 12 个样例单词，并且不连接生产环境的云数据库、用户记录或 AI 配额。

## 常见问题

- **我可以直接在 GitHub 网页里玩拾光吗？** 不行。GitHub 是源码托管平台，不是微信小程序运行容器。
- **扫码会进入你们的小程序还是我的复制品？** 官方线上小程序码进入维护者发布的正式版；克隆源码再部署的项目属于开发者自己的环境。
- **我需要付钱或登录 GitHub 吗？** 普通微信用户不需要 GitHub。自行部署者可能产生云开发或模型费用。
